Tubular Trefoil

  
Same projection pipeline as the classic donut — only the center path changed from a circle to a trefoil knot. The tube is still a circle of radius R₁ swept along that path.

  
trefoil(t):

  x = sin t + 2 sin 2t

  y = cos t − 2 cos 2t

  z = −sin 3t


then rotate A,B → project → 1/z → luminance
  
  
Tap = pause · Drag = steer · Double-tap = reset
